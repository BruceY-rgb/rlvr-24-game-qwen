# 24-Game RLVR 评估与消融实验报告（B 同学）

## 1. 实验设置

- **模型**：`Qwen/Qwen2.5-1.5B-Instruct` + LoRA(r=16, α=32)，GRPO/RLVR 训练。
- **训练**：TRL `GRPOTrainer`，400 step（≈0.33 epoch），lr 5e-6，num_generations 4，bf16，昇腾 910B4 (ModelArts)。
- **奖励**：`reward = 1.0·exact + 0.3·legal + 0.2·format + 0.2·closeness`
  （exact=是否等于目标；legal=表达式合法且恰好用一次每个数；format=是否符合 `<think>…</think><answer>…</answer>`；closeness=结果与目标的接近度）。
- **数据（6 个评估 split）**：dev 136 / ood_test 136 / hard_test 100 / unsolvable 100 / countdown_ood 2000 / countdown_unique 2000。
- **评估口径**：小 split（dev/ood/hard/unsolvable）采样 temperature=0.8、k=4，报 pass@4；countdown 两个全量、greedy、k=1；batch=96。
- **三方对照**：`base`（未训练 Qwen）/ `trained`（checkpoint-400）/ `solver`（精确搜索，可解上界）。

> **评估脚本 bug 修复（重要）**：原 `eval.py` 用 chat 模板构造 prompt，而 TRL 训练吃的是数据集里的**纯文本 `prompt` 列**，两者不一致导致模型推理时格式崩溃、`format_rate` 虚低（实测从 0 → 修复后 0.55+）。已改为与训练完全一致的纯文本 prompt。另外为可行性加了**批量生成**（吞吐提升约 8 倍）。

## 2. 任务①②：全量评估 + 精确搜索基线

| 指标 | split | solver | base | trained |
|---|---|---|---|---|
| pass@4 | dev | 1.000 | 0.007 | **0.066** |
| pass@4 | ood_test | 1.000 | 0.037 | **0.074** |
| pass@4 | hard_test | 1.000 | 0.000 | **0.070** |
| pass@1 | countdown_ood | 1.000 | 0.001 | 0.013 |
| pass@1 | countdown_unique | 1.000 | 0.000 | 0.011 |
| legal_rate | dev | 1.000 | 0.051 | **0.581** |
| format_rate | dev | 1.000 | 0.110 | **0.551** |
| format_rate | countdown_ood | 1.000 | 0.198 | **0.918** |

**结论：**
1. **RL 主要学会了"形式合规"**：format_rate 提升约 5 倍、legal_rate 约 11 倍。
2. **精确解题能力小幅提升但绝对值低**：pass@4 base→trained 约 9 倍（dev 0.007→0.066），但离 solver 的 1.0 上界很远 → 训练不充分（仅 0.33 epoch）。
3. **OOD（countdown，任意目标值）**：format 泛化极好（0.92），但解题能力没泛化（pass≈0.01）→ 模型学到的是"形式"而非"算法"。

## 3. 任务④：幻觉检测（unsolvable，100 道无解题）

| split | solver | base | trained |
|---|---|---|---|
| hallucination_rate | 0.000 | **1.000** | **0.990** |

- **定量**：理想模型（solver）在无解题上输出空答案，幻觉率 0；base 100% 硬编算式；trained 仍 99%。
- **定性**：
  - base：输出大段 markdown 推理（不守格式），最终给错误算式。
  - trained：输出**简洁算式**（学会了格式），但要么用**不存在的数字**（如 `[1,1,1,1] → (6*9)*(7*8)`），要么算错（`(1+1)*1*1=2`）。
- **结论**：**RL 没有抑制幻觉，反而让模型"更自信地简洁瞎编"**。根因：当前 reward（exact/legal/format/closeness）全都奖励"产出一个答案"，没有任何"无解时拒答"的激励。

## 4. 任务③：消融实验（每个 reward 分量的贡献）

**方法**：从同一基座、用**相同环境/超参**各重训 400 step：`full`（全奖励基线）、`no_legal`、`no_format`、`no_closeness`（exact 始终保留，是核心可验证信号）。在 dev + unsolvable 上评估对比。

> 注：基线用同环境重训的 `ab_full`（而非原 checkpoint-400），因为原 checkpoint 训练环境不同；只有同环境对照才公平。

### dev split

| 指标 | ab_full(基线) | −closeness | −format | −legal |
|---|---|---|---|---|
| format_rate | 0.897 | 0.706 | **0.191** | 0.904 |
| legal_rate | 0.412 | 0.243 | 0.287 | **0.243** |
| pass@4 | 0.022 | 0.051 | 0.059 | **0.015** |

### unsolvable split

| 指标 | ab_full(基线) | −closeness | −format | −legal |
|---|---|---|---|---|
| format_rate | 0.880 | 0.700 | **0.160** | 0.900 |
| legal_rate | 0.310 | 0.320 | 0.380 | **0.170** |
| hallucination_rate | 0.970 | 1.000 | 1.000 | 0.990 |

### 训练末段 reward（各自满分不同，仅供参考）

| 模型 | final train reward | 满分 | 归一化 |
|---|---|---|---|
| full | 0.402 | 1.7 | 0.236 |
| no_legal | 0.272 | 1.4 | 0.194 |
| no_format | 0.277 | 1.5 | 0.185 |
| no_closeness | 0.240 | 1.5 | 0.160 |

### 逐分量贡献分析

1. **format reward —— 贡献最大、信号最干净**：去掉后 format_rate 从 0.88-0.90 **暴跌到 0.16-0.19**（回落到接近 base 水平）。说明 **format reward 几乎是模型学会 `<think><answer>` 格式的唯一驱动**。
2. **legal reward —— 负责合法性**：去掉后 legal_rate 下降（dev 0.412→0.243），且 pass@4 最低（0.015）——不再被激励产出"合法可计算"的表达式。副作用：去掉 legal 后 **format_rate 反而最高（0.90）**，说明奖励项之间存在"学习注意力竞争"。
3. **closeness reward —— 贡献最弱/最不明确**：去掉后 format、legal 略降，但 pass@4 反而升（0.022→0.051，在低基数采样噪声范围内）。单独看不出强因果作用。
4. **幻觉无法靠现有任一分量抑制**：去掉任何分量后 unsolvable 幻觉率仍 0.97-1.00（去掉 closeness/format 后甚至升到 1.00）。再次印证需要专门的"拒答"机制。

---

## 5. 关键结论

1. 小模型 + 短训练（0.33 epoch）下，**RLVR 主要带来"形式合规"（格式+合法），精确解题提升有限**。
2. 奖励分量贡献排序：**format（格式）> legal（合法性）≫ closeness（接近度，贡献微弱）**；exact 是基石未参与消融。
3. **幻觉是当前奖励体系的盲区**——没有任何分量能让模型在无解题上拒答；需引入"无解样本 + 拒答奖励"。
4. **OOD 上格式可泛化、能力不泛化**——警惕"形式正确"误判为"学会推理"。

## 6. 局限与改进建议

- 训练仅 400 step / 0.33 epoch，pass 绝对值低；增大训练量预计能显著提升解题率。
- 评估口径混合（小 split 采样、countdown greedy），countdown 的 format 偏高有口径因素；统一口径可更可比。
- 消融模型受机时所限只评了 dev + unsolvable；可补 ood/hard 以增强结论稳健性。
- 抑制幻觉：在训练集混入无解样本，并对"无解时输出空答案"给正奖励、对"无解硬编"给负奖励。
